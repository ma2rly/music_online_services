# Лабораторная работа: Музыкальный онлайн-сервис

Лабораторная работа по объектно-ориентированному программированию на **Python 3.10+**

Это учебная консольная модель музыкального сервиса: каталог исполнителей и треков, пользователи, плейлисты, альбомы, жанры, лейблы, тарифы, подписки, избранное, отзывы и история прослушиваний. Воспроизведение аудио и подключение к настоящему серверу не входят в задачу.

## Возможности

- **CRUD** для исполнителей, треков, пользователей и плейлистов: создание, просмотр, изменение, удаление
- Добавление треков в плейлисты и удаление из плейлистов
- Поиск треков по части названия без учёта регистра
- Создание альбомов, жанров, лейблов, тарифов, подписок, отзывов, избранного и записей о прослушиваниях
- Сохранение каталога в **JSON** и **XML**, чтение из обоих форматов
- Проверка ссылок между объектами и данных полей, обработка стандартных и собственных исключений
- Консольное меню, которое продолжает работу после некорректного ввода
- **48 автоматических тестов** на `unittest`

## Как запустить

Нужен Python версии 3.10 или новее, сторонние библиотеки для работы программы не требуются.

**В PyCharm:** `File → Open` → выберите распакованную папку `music_online_service` → откройте `main.py` → `Run 'main'`.

**Из терминала** в корне проекта:

```bash
python main.py
```

На Windows, если `python` не распознаётся, попробуйте `py main.py`.

Программа при запуске читает образец `data/catalog.json` (если файл существует). Чтобы увидеть коллекции, выберите `1` и `30`.

## Главное меню и CRUD

| Действие | Пункт меню |
| --- | --- |
| Показать исполнителей, треки, пользователей и плейлисты | `1` |
| Создать исполнителя, пользователя, трек, плейлист | `2–5` |
| Добавить/удалить композицию в плейлисте | `6`, `9` |
| Найти композицию | `8` |
| Сохранить / загрузить JSON | `10` / `11` |
| Сохранить / загрузить XML | `12` / `13` |
| Изменить / удалить исполнителя | `14` / `15` |
| Изменить / удалить пользователя | `16` / `17` |
| Изменить / удалить трек | `18` / `19` |
| Изменить / удалить плейлист | `20` / `21` |

**Пример проверки CRUD:** выберите `2` и создайте исполнителя, затем `1` для просмотра, `14` для изменения имени и `15` для удаления. Если исполнитель уже используется в треке или альбоме, программа не даст удалить его до удаления зависимых данных — это сохраняет целостность каталога.

## Классы и архитектура

В предметной области **13 классов**: `Artist`, `Track`, `Listener`, `Playlist`, `Album`, `Genre`, `RecordLabel`, `SubscriptionPlan`, `Subscription`, `Favorite`, `Review`, `ListeningRecord`, `Catalog`. Другие классы обеспечивают работу программы, файловое хранение и обработку ошибок.

Использована слоистая архитектура, как в образце лабораторной:

```text
music_online_service/
├── main.py                         точка входа
├── domain/
│   ├── models.py                   четыре основных сущности и Catalog
│   ├── entities.py                 восемь дополнительных сущностей
│   ├── exceptions.py               собственные исключения
│   └── repository.py               абстрактный интерфейс хранилища
├── application/
│   └── music_service.py            методы работы с каталогом
├── infrastructure/
│   ├── json_repository.py          JSON: загрузка и сохранение
│   └── xml_repository.py           XML: загрузка и сохранение
├── presentation/
│   └── console.py                  консольное меню, ошибки ввода
├── data/
│   ├── catalog.json                пример данных
│   ├── catalog.xml                 те же данные в XML
│   └── СТРУКТУРА_ДАННЫХ.md          описание форматов и полей
├── tests/                          тесты на unittest
├── README.md
```

`domain` содержит сущности и проверку отношений, `application` — бизнес-операции, `infrastructure` — файловые репозитории, `presentation` — пользовательское меню.

## Данные JSON и XML

Оба формата описывают один и тот же каталог. Данные разделены на 12 коллекций: `artists`, `tracks`, `listeners`, `playlists`, `albums`, `genres`, `labels`, `plans`, `subscriptions`, `favorites`, `reviews`, `history`.

Пример JSON:

```json
{
  "artists": [{"id": 1, "name": "My Chemical Romance"}],
  "tracks": [{"id": 1, "title": "Helena", "artist_id": 1, "duration_seconds": 202, "genre": "Emo", "album_id": null}]
}
```

Это **фрагмент**, а не полный JSON-файл: для загрузки требуется также `listeners` и `playlists`, а дополнительные разделы допустимо оставить пустыми. Полные корректные файлы находятся в `data/`

Эквивалентный фрагмент XML:

```xml
<music_service version="2">
  <artists><artist id="1"><name>My Chemical Romance</name></artist></artists>
  <tracks><track id="1" artist_id="1" duration_seconds="202">
    <title>Helena</title><genre>Emo</genre>
  </track></tracks>
</music_service>
```

Чтение и запись реализованы через стандартные модули Python `json` и `xml.etree.ElementTree`. Если файл содержит неверные данные, возникает `DataFormatError`, и текущее состояние каталога сохраняется. Поддерживается также загрузка XML версии `1` из предыдущей версии проекта.

## Обработка ошибок

- **Собственные:** `MusicServiceError`, `ValidationError`, `DuplicateError`, `NotFoundError`, `DataFormatError`
- **Встроенные:** `ValueError`, `FileNotFoundError`, `PermissionError`, `OSError`, `EOFError`, `KeyboardInterrupt`

Некорректные ID, пустые имена, неправильная оценка или удаление связанной записи приводят к понятному сообщению об ошибке, а не к аварийному завершению программы. При `Ctrl+C` пользователь добровольно завершает сеанс.
