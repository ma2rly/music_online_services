# Схема данных музыкального онлайн-сервиса

В качестве первичного представления используется словарь Python с четырьмя списками. Форматы JSON и XML описывают **одни и те же объекты**. Полные примеры находятся в `catalog.json` и `catalog.xml`.

| Сущность | Поля | Типы | Значение |
|---|---|---|---|
| Artist | `id`, `name` | int, str | Исполнитель |
| Track | `id`, `title`, `artist_id`, `duration_seconds`, `genre` | int, str, int, int, str | Композиция и ID исполнителя |
| Listener | `id`, `username` | int, str | Пользователь |
| Playlist | `id`, `name`, `owner_id`, `track_ids` | int, str, int, list[int] | Плейлист пользователя и список ID треков |

## JSON

Корневой объект:

```json
{
  "artists": [{"id": 1, "name": "Кино"}],
  "tracks": [{"id": 1, "title": "Группа крови", "artist_id": 1, "duration_seconds": 287, "genre": "Рок"}],
  "listeners": [{"id": 1, "username": "student"}],
  "playlists": [{"id": 1, "name": "Любимое", "owner_id": 1, "track_ids": [1]}]
}
```

## XML

Корень — `<music_service version="1">`. Внутри расположены контейнеры `<artists>`, `<tracks>`, `<listeners>`, `<playlists>`. Идентификаторы и внешние ссылки представлены атрибутами, тексты — дочерними тегами; ID треков плейлиста — тегами `<track id="..."/>` внутри `<track_ids>`.

```xml
<?xml version="1.0" encoding="utf-8"?>
<music_service version="1">
  <artists><artist id="1"><name>Кино</name></artist></artists>
  <tracks><track id="1" artist_id="1" duration_seconds="287"><title>Группа крови</title><genre>Рок</genre></track></tracks>
  <listeners><listener id="1"><username>student</username></listener></listeners>
  <playlists><playlist id="1" owner_id="1"><name>Любимое</name><track_ids><track id="1"/></track_ids></playlist></playlists>
</music_service>
```

## Ограничения

- Все `id`, `artist_id`, `owner_id`, `duration_seconds` и ID внутри плейлиста — **положительные целые числа**.
- Имена, названия и жанры — **непустые строки**.
- `id` уникален внутри раздела.
- `Track.artist_id` должен ссылаться на существующего `Artist`.
- `Playlist.owner_id` должен ссылаться на существующего `Listener`.
- Каждый ID из `Playlist.track_ids` должен существовать в разделе `tracks` и не повторяться в том же плейлисте.

Это проверяет `Catalog.from_dict()` при загрузке. При нарушении схемы файловый репозиторий поднимает `DataFormatError`, а консоль выводит понятное сообщение и продолжает работу.
